The experimental data can be downloaded from XX. THey should be added as a folder data. 

- get_participant_characteristics: computes participants' mass and BMI from a static trial.
- residual_analysis: residual analysis to determine the filder cut-off frequency for the belt speed data
- final load and plot data: example how to load the exerimental data, & data visualization
- lopo / loso: leave-one-participant-out / leave-one-speed-out cross-validation on experimental data
- plot loo results: visualize the results of the leave one out cross-validations
- final_optimization: final fit of the realistic treadmill controller on all experimental data
- store data: store the processed experimental data in a csv to be loaded and used in optimcal control simulations
